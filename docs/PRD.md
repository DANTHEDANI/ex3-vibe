# Product Requirements Document (PRD)

## 1. רקע ומטרת הפרויקט
הפרויקט מיועד למדל בעיית החלטה של סוכן הממליץ על אימונים יומיים למתאמן, במטרה למקסם את איכות האימון לאורך זמן ולהימנע מעומס יתר (Overload) תוך שמירה על איזון.

## 2. קהל יעד
מתאמנים המעוניינים לקבל תוכנית אימון אדפטיבית שמתאימה למצבם בזמן אמת.

## 3. יעדים ומדדי הצלחה (KPI)
- **מדד עיקרי**: סוכן ה-RL לומד מדיניות שמשפרת את התגמול (Reward) ומקטינה את שונות העומס לאורך זמן.
- **יעד**: השוואה ברורה בין אלגוריתם REINFORCE לבין A2C.

## 4. דרישות
### פונקציונליות
- הורדת נתונים מ-Kaggle.
- סינון ויצירת מסלול היסטורי (Trajectory) של מתאמן.
- אימון מודל סביבה (LSTM World Model) לחיזוי מצב המתאמן.
- אימון סוכן RL (REINFORCE & A2C).
### א-פונקציונליות
- ארכיטקטורת קוד בסטנדרטים של "רמת הצטיינות יתרה".
- 85% כיסוי בדיקות, 0 שגיאות Linter.

## 5. ציר זמן ואבני דרך
1. הכנת הנתונים
2. אימון מודל הסביבה (LSTM)
3. אימון ומימוש סוכני ה-RL
4. בדיקות יחידה ומסקנות
